# Página: Agendamentos (`/agendamentos`)

Reserva de áreas comuns do condomínio (salão de festas, churrasqueira, etc.).

---

## Disponibilidade por plano

Disponível em todos os planos (OmniGO, Omni+, OmniUltra).

---

## Fluxo

1. Morador seleciona a área, data e horário desejados.
2. O sistema verifica conflitos de horário.
3. ADMIN pode ver e cancelar qualquer agendamento.
4. Filtrado por `condominioUUID`.
