# Página: Assembleia (`/enquetes`)

Enquetes e votações para decisões do condomínio.

---

## Fluxo

1. ADMIN cria uma enquete com pergunta, opções e prazo.
2. Moradores votam enquanto a enquete está aberta.
3. Resultado fica visível após o encerramento.
4. Filtrado por `condominioUUID`.

---

## Acesso

Todos os roles autenticados.
