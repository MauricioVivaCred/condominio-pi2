# Página: Chat (`/chat`)

Canal de comunicação em tempo real entre moradores e administração.

---

## Acesso

Todos os roles autenticados exceto PORTEIRO (o botão flutuante de chat não aparece para PORTEIRO).

---

## Peculiaridades

- O botão flutuante do chat aparece em todas as páginas do app via `app-layout.tsx`, exceto para PORTEIRO.
- Quando o usuário está na rota `/chat`, o botão fica com fundo azul escuro indicando página ativa.
