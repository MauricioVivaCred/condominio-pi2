# Página: Manutenção (`/manutencao`)

Registro e acompanhamento de solicitações de manutenção no condomínio. A rota `/maresia` redireciona permanentemente para `/manutencao` (nome legado).

---

## Fluxo

1. Morador abre uma solicitação com descrição, localização e foto opcional.
2. ADMIN acompanha o status e atualiza o andamento.
3. Filtrado por `condominioUUID`.

---

## Acesso

Todos os roles autenticados.
