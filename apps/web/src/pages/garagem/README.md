# Página: Garagem (`/garagem`)

Mapa interativo e controle de vagas da garagem do condomínio.

---

## Fluxo

1. Exibe o mapa da garagem com vagas livres e ocupadas.
2. ADMIN pode associar vagas a moradores.
3. MORADOR visualiza sua(s) vaga(s).
4. Filtrado por `condominioUUID`.

---

## Acesso

ADMIN, MORADOR e PORTEIRO.
