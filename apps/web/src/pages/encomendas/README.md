# Página: Encomendas (`/encomendas`)

Registro e notificação de encomendas recebidas na portaria.

---

## Fluxo

1. Porteiro ou ADMIN registra a encomenda com nome do destinatário e descrição.
2. Morador é notificado e confirma a retirada.
3. Filtrado por `condominioUUID`.

---

## Acesso

ADMIN, MORADOR e PORTEIRO.
