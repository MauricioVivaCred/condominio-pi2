# Página: Ocorrências (`/ocorrencias`)

Registro e acompanhamento de ocorrências no condomínio.

---

## Disponibilidade por plano

Disponível apenas para **Omni+** e **OmniUltra**. No plano OmniGO, o link não aparece no sidebar.

---

## Fluxo

1. Morador registra uma ocorrência com descrição, categoria e foto opcional.
2. ADMIN acompanha, responde e fecha ocorrências.
3. Filtrado por `condominioUUID`.
